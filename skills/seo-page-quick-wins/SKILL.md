# SEO page quick wins

## Purpose

A single-page SEO audit tends to return a long list that nobody acts on. This skill returns two or three wins, each traceable to a mechanism and checkable by the reader. A claim that cannot be checked is a preference, not a quick win.

## When to use

- One page's SEO status is unclear, and the team wants the fastest wins.
- A client or stakeholder asks why a page would rank, or wants a recommendation defended.

Route elsewhere when:
- The question is topics and the content roadmap. Use `seo-topic-research`.
- The question is whether a keyword can be won. Use `seo-serp-qualification`.

## Inputs

- The page URL and the target query.
- The operator's working hypothesis for the page, such as a title that does not match the query, or thin content.
- The site context the page sits in: its internal links and the pages that point to it.
- A checkable reference for each mechanism that will be cited. Where a reference cannot be checked, the claim is a hypothesis.

## Procedure

1. **Start from a direction.** Write the operator's read of the page in one line before the audit. The skill confirms or challenges that read. It does not choose the strategy. An audit with no direction returns a generic list.
2. **Read the page as a search system would.** Check the title against the query, the headings, the depth and originality of the main content, the internal and inbound links, the freshness signals, and the site context. Mark the weak elements. These form the shortlist.
3. **Attach a receipt to each candidate.** Name the mechanism that makes the change work and the documented source that describes it. A win that cannot be tied to a mechanism is a preference. Drop it, or label it a hypothesis.
4. **State what the evidence proves.** A documented approach shows how a system is designed to treat a problem. A documented stored signal shows the signal exists. Neither proves that the signal is live or how heavily it is weighted. Say which applies.
5. **Rank by effort against impact.** Return the top two or three. Return two if only two are solid.
6. **Give four things for each item.** The action, the page evidence that it is missing, the mechanism, and the reference to check.

## Output

- The operator's direction, restated in a line.
- Two or three ranked quick wins, each with its action, page evidence, mechanism, reference and strength of evidence.
- Any candidate dropped for lacking a receipt, listed in one line each.

## Quality bar

Every win has a mechanism and a checkable reference. No reference is invented, and an unverifiable one is presented as a hypothesis. The output is capped at three. Watch for an audit run without a direction, a list longer than three, and a claim stated as proven when the evidence only shows a design intent.

## Rules

- Attach a checkable reference to every quick win, and confirm it before citing it.
- Distinguish what the evidence proves from what it does not.
- Cap the output at the few highest-impact wins.
- Never invent a reference, identifier or field name.
- The skill grounds the operator's direction. It does not pick the strategy.
